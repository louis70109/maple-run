# 楓之谷跑跑（MapleRun）規劃書

類似「跑跑薑餅人」的橫向自動跑酷遊戲，美術與世界觀採用楓之谷元素。
角色與怪物是楓之谷原本的**逐格動畫**（從 maplestory.io 取得並打包進 repo），道具圖示取自 `louis70109/rms-data`。
網頁遊戲，部署在 GitHub Pages，可安裝成 PWA 離線玩。

## 1. 核心玩法

| 項目 | 設計 |
|------|------|
| 移動 | 角色自動往右跑，玩家只負責 **跳躍**（可二段跳）和 **滑行** |
| 體力 | HP 每秒自動減少（薑餅人的能量條），撿 **紅藥水 +25／藍藥水 +45** 補血；HP 歸零就結束 |
| 障礙 | 地面怪（跳過）、高大怪（二段跳）、飛行怪（滑過）、坑洞（掉下去扣 HP，在下一塊地復活） |
| 收集 | 楓幣（分數）、楓幣袋、隨機道具圖示（+300）、浮空平台上的楓幣 |
| 道具 | 加速（無敵衝刺，圖示用楓之谷「輕功」）、磁鐵（吸楓幣）、巨大化（撞飛怪物） |
| 關底 | 每關最後出現該地區 BOSS，丟高低兩種攻擊；撐過時間就過關並回復 30% HP |
| 循環 | 8 個地區跑完後回到弓箭手村開始下一輪，數值持續成長，屬於無盡模式 |

### 職業（各有一個小加成）
劍士 HP +20%、法師道具時間 +50%、弓箭手跳更高、盜賊三段跳、海盜楓幣 +30%。
每個職業穿各自的楓之谷裝備（頭盔、巫師帽、獵人帽、盜賊頭巾、海盜頭巾）並拿對應武器。

### 職業攻擊
按 **Ctrl / J / F** 或手機的「攻擊」鍵出招，按住會依冷卻時間連續攻擊（跟楓之谷一樣）。
招式動作、出招特效、飛行道具和命中火花都是楓之谷原本的圖（`fx-<職業>`）。

| 職業 | 招式 | 類型 | 特色 | 冷卻 |
|------|------|------|------|-----:|
| 劍士 | 劍氣縱橫（Slash Blast） | 近戰 | 前方 165px，最多 3 隻，一下打倒高大怪 | 0.5s |
| 法師 | 能量箭（Energy Bolt） | 遠程 | 魔法球，射程 560px | 0.55s |
| 弓箭手 | 斷魂箭（Arrow Blow） | 遠程 | 箭最快、射程最遠，可穿透 1 隻 | 0.45s |
| 盜賊 | 雙飛斬（Lucky Seven） | 遠程 | 一次丟兩支飛鏢 | 0.5s |
| 海盜 | 翻身踢（Sommersault Kick） | 近戰 | 範圍較短但較高，最多 4 隻，一下打倒高大怪 | 0.42s |

- 一般怪物和飛行怪 1 下倒，高大怪物要 2 下（劍士、海盜 1 下）
- 打中會跳出楓之谷風格的傷害數字（20% 暴擊，粉紅色），沒倒的怪會播受擊動作並被打退
- 打倒的怪播放死亡動畫、掉一袋楓幣，分數 +150×關卡
- 打怪是「跳過去」之外的另一個選擇：遠程職業可以先清掉前方的怪，近戰要等靠近再出招

### 左右移動
←／→（A／D）或手機左下 ◀ ▶ 可以在畫面上前後移動（地面照樣自動捲動）。
往前：主動貼近 BOSS 輸出，但小怪和 BOSS 的招式來得更快，撞到 BOSS 會受傷被彈開，貼太近 BOSS 會放**不能格擋的地面震波**（要跳）。
往後：反應時間比較多，比較安全。

### 職業大絕招（K／L 或技能按鈕）
冷卻時間到才能放，打倒怪物每隻縮短 0.8 秒；開場先充好 40%。特效都是楓之谷原本的技能圖（`sk-<職業>`）。

| 職業 | 大絕招 | 畫面變化 | 效果 | 冷卻 |
|------|--------|----------|------|-----:|
| 劍士 | 突進（Rush） | 紫色衝刺、畫面震動 | 衝過大半個畫面撞飛沿途所有怪；有 BOSS 時直接衝到 BOSS 面前（BOSS −25） | 14s |
| 法師 | 暴風雪（Blizzard） | 畫面變冰藍、下雪、冰柱落下 | 冰柱一根根砸向每隻怪；BOSS 冰凍 3 秒不能行動，招式全碎 | 16s |
| 弓箭手 | 暴風神射（Hurricane） | 風的線條、連射箭流 | 3 秒連射穿透箭，貫穿一整排 | 15s |
| 盜賊 | 楓幣炸彈（Meso Explosion） | 紫色閃光、楓幣一路炸過去 | 畫面上所有楓幣引爆（楓幣加倍收下），炸到附近的怪；楓幣越多越痛 | 14s |
| 海盜 | 炸彈桶（Barrel Bomb） | 燃燒的大木桶滾出去、大爆炸 | 撞飛沿途的怪，碰到 BOSS 或滾到邊緣時爆炸（BOSS −30） | 15s |

### 近戰 vs 遠程：遠程清小怪、近戰打 BOSS
| | 近戰（劍士、海盜） | 遠程（法師、弓箭手、盜賊） |
|---|---|---|
| 一般關卡 | 一次打多隻、高大怪一下倒、冷卻短 | 遠遠就能清掉前方的怪 |
| 打 BOSS（每下） | 劍士 5、海盜 4 | 法師 1.5、弓箭手 1.2、盜賊 0.7×2 |
| BOSS 的招式 | 揮砍可以**格擋**（震波除外） | 只能跳或滑行閃開 |

### BOSS 戰
- 撐過時間就過關（+1000×關卡）；時間內把 BOSS 血量打光**提早過關、獎勵加倍**（+2000×關卡）
- BOSS 輪流：站在遠處丟攻擊 1.6～2.2 秒 → 衝到角色前方停 1.5 秒（不丟攻擊，近戰打得到）→ 退回去
- 角色貼太近時 BOSS 每 1.3 秒放一次地面震波（不能格擋）
- BOSS 血量由 GM 設定（`bossHp`，每關 +12%）
- 自動測試量的結果（角色無敵、按住攻擊）：

| | 待在原位 | 原位＋大絕招 | 主動貼近＋大絕招 |
|---|---|---|---|
| 近戰 | 打掉約一半 | 有時打得倒 | 三個頻道第 1～8 關都打得倒 |
| 遠程 | 約 1/3 | 約 6～7 成 | 靠近沒有好處，打不倒 |

### 動畫
| 角色狀態 | 楓之谷動作 |
|----------|-----------|
| 跑步 | `walk1`，跑越快腳步越快 |
| 跳躍 | `jump`；二段跳時會向前翻滾一圈 |
| 滑行 | `prone`（趴下） |
| 受傷 | `alert`，並閃紅光 |
| 攻擊、撞飛怪物（加速／巨大化） | 各職業的攻擊動作（揮劍、射箭…） |

怪物播放 `move`（飛行怪是 `fly`）動畫，被打中時換成 `hit1`、被打倒時播 `die1`；BOSS 平常播 `move`，丟攻擊時播 `attack1`。
標題畫面的背景是角色一直在跑的展示，選職業時被選中的角色會跑步、其他角色站著。

## 2. 頻道＝難度

| 頻道 | 難度 | 起始速度 | 最大 HP | HP 消耗 | 分數倍率 |
|------|------|---------:|--------:|--------:|---------:|
| CH.1 新手 | 簡單 | 330 | 120 | 2.2/秒 | ×1 |
| CH.2 冒險者 | 普通 | 390 | 100 | 3.0/秒 | ×1.5 |
| CH.3 勇者 | 困難 | 450 | 90 | 3.2/秒 | ×2 |

每個頻道有自己的排行榜。以上是預設值，GM 可以隨時調整。

## 3. 漸進難度

所有參數定義在 `src/params.js`（遊戲、GM 介面、驗證共用同一份）。`stageParams(頻道設定, 關卡)` 算出每關實際數值：

- 速度 = 起始速度 + 每關加速 ×（關卡−1），不超過速度上限；**同一關內也會平滑加速**，跑到關底時剛好接近下一關速度
- HP 消耗、障礙密度、撞怪傷害、坑洞機率、關卡長度、BOSS 時間與攻擊頻率都隨關卡提高
- 藥水間隔隨關卡拉長

地形是程序化產生（`src/level.js`），但有公平性保證：
- 坑洞寬度永遠小於當下速度的二段跳距離（含 38% 餘裕）
- 兩個地面怪之間一定留有落地反應距離
- 開頭一段沒有障礙，BOSS 階段只有平地

## 4. GM 設定介面（`#gm`）

網址加上 `#gm`（或標題畫面的「GM 設定」）進入：

1. 三個頻道分頁，每個參數有拉桿＋數字欄位、說明、預設值與目前發佈值；改過的參數會標示
2. **難度成長預覽表**：直接看到第 1～16 關的速度、消耗、密度、坑洞、傷害、BOSS
3. GM 公告：顯示在標題畫面的跑馬燈
4. **本機預覽**：GM 先用草稿設定自己試玩，不影響其他玩家
5. **發佈給所有玩家**：用 GitHub API 把 `config.json` commit 到 repo → GitHub Pages 重新部署 → 所有玩家下次開遊戲就套用
6. 也可以匯出／匯入 `config.json`，手動 commit

### 為什麼這樣做
GitHub Pages 是純靜態網站，沒有後端可以存「全體玩家共用的設定」。
把設定放在 repo 的 `config.json`，好處是**不需要任何額外服務**、有 git 歷史可以回溯每次調整。
權限控管交給 GitHub：只有拿到該 repo 寫入權 token 的人才能發佈，前端不做假的密碼保護。

缺點是生效要等 Pages 部署（約 1 分鐘）。如果之後需要「即時生效」或「全球排行榜」，
可以把 `store.js` 的讀寫換成 Firebase / Supabase，其他程式不用動。

## 5. 技術架構

```
index.html / styles.css     畫面與選單（DOM）
src/main.js                 畫面流程、輸入、排行榜畫面、路由
src/game.js                 遊戲迴圈、物理、碰撞、Canvas 繪圖
src/level.js                程序化地形（純資料，可測試）
src/params.js               難度參數定義、預設值、驗證、成長公式
src/themes.js               地區、怪物、BOSS、職業、道具圖
src/physics.js              物理常數、可重現亂數
src/store.js                config.json 載入、GM 草稿、本機排行榜
src/gm.js                   GM 設定介面與 GitHub 發佈
src/sprites.js              逐格動畫：讀 sprites.json、依時間選格、以腳底為基準繪製
src/audio.js                WebAudio 合成音效（不需音檔）
scripts/fetch_sprites.py    從 maplestory.io 抓角色／怪物動畫，打包成 assets/sprites/
sw.js / manifest.webmanifest  PWA
config.json                 GM 發佈的難度設定
```

- 純原生 JavaScript（ES modules）＋ Canvas 2D，**沒有建置步驟**，push 就能部署
- 邏輯解析度 960×540，依螢幕等比例縮放；手機用左右兩顆大按鈕，桌機用鍵盤
- PWA：殼與程式網路優先（有網路永遠最新）、圖片快取優先（玩過一次就能離線）、`config.json` 網路優先（GM 新設定上線即生效）

## 6. 部署

`.github/workflows/pages.yml`：push 到 `main` → 跑測試 → 組出 `_site/` → 部署到 GitHub Pages。
service worker 版本號自動換成 commit SHA。

**第一次需要手動**：repo Settings → Pages → Source 選 **GitHub Actions**。

## 7. 測試

`npm test`（Node 22，無相依套件）：
- 參數範圍、預設值、成長曲線單調遞增、`config.json` 合法
- 地形公平性（坑洞跳得過、怪物間距、BOSS 階段只有平地）
- **自動玩家**：在不畫圖的情況下跑真正的遊戲邏輯，確認三個頻道都能過好幾關，且困難比簡單更早結束
